# OHM content standards

One system for every client. The shoot date is the key that ties everything together.

## 1. One link
Everything lives in **OHM CLIENTS** (Google Drive, inside OHM SOCIAL FILES). One folder per current client. Nobody works out of old folders or personal links.

https://drive.google.com/drive/folders/1WD7bOn5UUWQ69L6ftSwRTHulK8i_TeiK

## 2. Client folder rules
- Each client folder holds the **last 2 weeks of filming** (iFAB: last 3 weeks) plus an **Archive** folder.
- Anything older than that goes into that client's Archive. Nothing gets deleted.
- Check on the 1st and 15th of each month and move anything that aged out.
- No Unsorted folder. Every file goes where it belongs the day it is uploaded.

## 3. Footage folders and names (Tristen)
- Inside each client folder, new footage goes in **Reels**, **Drone** or **Photos**.
- File name: `CLIENT_TYPE_DATE_Subject_LABEL_001`
- Reel labels: HOOK (talking head hook), TALK (other talking head), BROLL, PRODUCT, EVENT.
- Details are in the labeling guide PDF.

## 4. The shot list is the center of every shoot
- It is **triggered when a shoot date is added, or when a bi-weekly block is set**. It is created and delivered before Tristen goes out, so there is no guessing.
- Shot list name: `CLIENT_SHOTLIST_DATE` (same date as the shoot, same date as the files).
- Every shot list has four parts:
  1. **Hooks to film.** Talking head hooks.
  2. **B-roll to get.** Specific shots.
  3. **Photos to get.** Team, job, product, location.
  4. **Must-gets.** Anything a specific calendar item needs, with the post it is for.
- Hooks, b-roll and directives are taken from **what is working for the top performers in that client's industry**, plus what is already performing for the client and what is missing from the archive.
- Griffin keeps every client on the calendar at least every two weeks, for anyone we can film for. That sets the dates that trigger shot lists.

## 5. How it connects
**Shoot date or bi-weekly block** -> **Shot list** (same date) -> **Footage** (same date in every file name) -> **Edit and design** (Hiroshi and Mafer pull by label) -> **Caption and schedule** (Valeria).

Same date everywhere means anyone can find the shot list, the footage and the post for any shoot.

## 6. Upload standard
- Upload to the client folder by the morning after the shoot.
- Name files before upload, not after.
- If something on the shot list was not filmed, note it at the top of the shot list so the next shoot picks it up.

## 7. Everyone on camera is cleared
No release tracking in names or folders.
